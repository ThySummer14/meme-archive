# 梗档案馆 Meme Archive

> 中文互联网梗的收集与归档。梗和生物一样有生命周期：不断冒出新的，旧的逐渐被遗忘。
> 档案馆的使命是——**在新梗淹没旧梗之前，把它们登记在册**。

- **阶段一**：梗的收集与结构化归档 ✅ 现有馆藏 **322 件**（2026-08-30 建库；2026-08-31 三轮扩录：B站/小黑盒专题 +26 件，B站考据UP主「梗指南」专题两批 +72 件，查漏补缺 +1 件）
- **阶段二**：Web 展馆 ✅ 基础版上线（2026-08-31，`site/` 目录；展柜 / 编年 / 搜索 / 筛选 / 卷宗详情已就绪，梗关联图与「每周上新」页待做）

### 预览展馆

```bash
python3 scripts/build.py                          # 数据变更后先构建
python3 -m http.server 8961 -d site               # 打开 http://localhost:8961
```

站点为纯静态（无依赖、无构建链），`site/data.js` 由 build.py 自动生成，勿手改。

## 数据模型

每件「藏品」一条记录：

| 字段 | 说明 |
|------|------|
| `id` | 全局唯一英文 id（kebab-case） |
| `name` | 梗名（`aliases` 存别名/变体） |
| `category` | 所属分类 id（合并时自动注入） |
| `year` | 走红/起源年份 |
| `origin` | 出处考据：谁说的、在哪火的 |
| `meaning` | 一句话释义 |
| `example` | 用法示例 |
| `status` | 生命周期状态（见下） |
| `platforms` | 主要流行平台 |
| `tags` | 补充标签（方言、空耳、AI、年度弹幕……） |
| `related` | 关联梗的 id |
| `source` | 来源链接（2024 年后的条目尽量带官方来源） |

## 生命周期状态

档案馆的核心视角不是「现在火不火」，而是**它在梗历史中的位置**：

| 状态 | 含义 | 例 |
|------|------|-----|
| `active` 现役 | 当季仍高频产出与使用 | 那咋了、包的、Labubu |
| `longevity` 长寿 | 爆发期已过，但已融入日常口语 | yyds、真香、内卷、吃瓜 |
| `revival` 复活 | 考古翻红 | 宫廷玉液酒 |
| `fading` 退烧 | 明显过气，主要剩回忆 | 绝绝子、科目三、挖呀挖 |
| `fossil` 化石 | 基本退网，进考古区 | 神马都是浮云、贾君鹏、蓝瘦香菇 |

## 收录原则

1. **官方榜单为锚点**：《咬文嚼字》年度十大流行语（2024/2025 已核）、国家语言资源监测中心年度十大网络流行语、《语言文字周报》十大网络流行语、B 站年度弹幕（2017–2025 全系列已收录）。
2. **考据源**：B站 UP 主「[梗指南](https://space.bilibili.com/94510621)」（752 期「XX是什么梗」系列，全量元数据已存 `data/sources/genzhi-752videos.json` 作为扩录池），新增条目普遍以对应视频链接为 `source`。
3. **网络通史兼顾**：从天涯/猫扑时代（打酱油、神马浮云）到短视频时代（奶绿波、龙虾），尽量每个年代都有代表件。
4. **来源标注**：扩录条目带 `source` 链接；更早条目来自编辑积累，待逐条补源。
5. **分类取核心属性**：一梗一分类，跨类特质放 `tags`（如「雨女无瓜」归影视梗、标签空耳）。
