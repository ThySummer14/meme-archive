# 梗档案馆 Meme Archive

> 中文互联网梗的收集与归档。梗和生物一样有生命周期：不断冒出新的，旧的逐渐被遗忘。
> 档案馆的使命是——**在新梗淹没旧梗之前，把它们登记在册**。

- **阶段一**：梗的收集与结构化归档 ✅ 现有馆藏 **333 件**（2026-08-30 建库；08-31 三轮扩录 +98 件；09-05 考据扩录 +8 件，「梗指南」752 期扩录池宣告全量过筛）
- **阶段二**：Web 展馆 ✅ 已上线 **https://thysummer14.github.io/meme-archive/**（2026-09-05，GitHub Pages；四大视图：展柜 / 编年 / 图谱 / 上新，搜索筛选卷宗齐备）

### 预览与部署

```bash
python3 scripts/build.py                          # 数据变更后先构建
python3 -m http.server 8961 -d site               # 本地预览 http://localhost:8961
```

- **线上**：https://thysummer14.github.io/meme-archive/（GitHub Pages，源为 `gh-pages` 分支 = `site/` 子树）
- **发版**：`git subtree push --prefix=site origin gh-pages`；更新 JS/CSS 后记得改 index.html 里的 `?v=` 版本号破缓存
- 站点为纯静态（无依赖、无构建链），`site/data.js` 由 build.py 自动生成，勿手改。

## 数据模型

每件「藏品」一条记录：

| 字段 | 说明 |
|------|------|
| `id` | 全局唯一英文 id（kebab-case） |
| `name` | 梗名（`aliases` 存别名/变体） |
| `category` | 所属分类 id（合并时自动注入） |
| `year` | 走红/起源年份 |
| `origin` | 出处考据：谁说的、在哪火的 |
| `meaning` | 一句话释义 |
| `example` | 用法示例 |
| `status` | 生命周期状态（见下） |
| `platforms` | 主要流行平台 |
| `tags` | 补充标签（方言、空耳、AI、年度弹幕……） |
| `related` | 关联梗的 id |
| `source` | 来源链接（扩录条目带考据视频/官方榜单来源） |
| `added` | 入馆日期（上新视图按此分组；新增条目必填） |

## 生命周期状态

档案馆的核心视角不是「现在火不火」，而是**它在梗历史中的位置**：

| 状态 | 含义 | 例 |
|------|------|-----|
| `active` 现役 | 当季仍高频产出与使用 | 那咋了、包的、Labubu |
| `longevity` 长寿 | 爆发期已过，但已融入日常口语 | yyds、真香、内卷、吃瓜 |
| `revival` 复活 | 考古翻红 | 宫廷玉液酒 |
| `fading` 退烧 | 明显过气，主要剩回忆 | 绝绝子、科目三、挖呀挖 |
| `fossil` 化石 | 基本退网，进考古区 | 神马都是浮云、贾君鹏、蓝瘦香菇 |

## 收录原则

1. **官方榜单为锚点**：《咬文嚼字》年度十大流行语（2024/2025 已核）、国家语言资源监测中心年度十大网络流行语、《语言文字周报》十大网络流行语、B 站年度弹幕（2017–2025 全系列已收录）。
2. **考据源**：B站 UP 主「[梗指南](https://space.bilibili.com/94510621)」752 期「XX是什么梗」系列已**全量过筛**（约 100 期入库/与馆藏重叠，其余因圈层过窄或存证不足暂缓），元数据存 `data/sources/genzhi-752videos.json`；入库条目普遍以对应视频链接为 `source`。
3. **网络通史兼顾**：从天涯/猫扑时代（打酱油、神马浮云）到短视频时代（奶绿波、龙虾），尽量每个年代都有代表件。
4. **来源标注**：扩录条目带 `source` 链接；更早条目来自编辑积累，待逐条补源。
5. **分类取核心属性**：一梗一分类，跨类特质放 `tags`（如「雨女无瓜」归影视梗、标签空耳）。
